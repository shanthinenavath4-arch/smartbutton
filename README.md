# SmartButton

A responsive interactive button project built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

https://shanthinenavath4-arch.github.io/smartbutton/

## ✨ Features

- Single Click interaction
- Double Click detection
- Hover interaction
- Enter & Space keyboard support
- Click counter
- Progress tracking
- Activity history
- Reset functionality
- Light / Dark theme
- LocalStorage data persistence
- Toast notifications
- Responsive design
- Loading & success animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- LocalStorage
- Git & GitHub
